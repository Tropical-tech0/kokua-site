# Kokua — site

Página institucional do Kokua, publicada em https://kokua.one pelo GitHub Pages.

- `index.html`: página em português.
- `en/index.html`: página em inglês.
- `img/`: ícone e capturas da app.
- `CNAME`: o domínio do site.

https://tropical-tech0.github.io/kokua-feeds/privacidade.html e
https://tropical-tech0.github.io/kokua-feeds/termos.html.
